## 1. Hien trang loi

### 1.1. Maven/JDK khong dong bo

- `pom.xml` ban dau khai bao Java 21:
  - `maven.compiler.source=21`
  - `maven.compiler.target=21`
  - `javafx.version=21.0.1`
- Moi truong terminal ban dau dang dung JDK 17.
- Khi chay `.\mvnw.cmd -q test`, Maven fail voi loi:
  - `invalid target release: 21`

Ket luan: build fail truoc khi vao test vi JDK runtime cua Maven thap hon target trong `pom.xml`.

### 1.2. Loi Mockito sau khi pull nhanh `han`

- Nhanh `origin/han` co commit:
  - `31f94bb chore: ha cap mock-maker xuong subclass de bypass Java 25 modules`
- Commit nay them file:
  - `src/test/resources/mockito-extensions/org.mockito.plugins.MockMaker`
- Noi dung cu:
  - `mock-maker-subclass`
- Trong khi `AuctionRoomServiceTest` dang dung:
  - `mockStatic(AuctionStateManager.class)`

Ket qua: `mock-maker-subclass` khong ho tro static mock, lam 4 test trong `AuctionRoomServiceTest` fail.

### 1.3. Loi khi co gang chay JDK 25 voi cau hinh cu

Khi ep Maven chay bang JDK 25 voi cau hinh cu:

- Mockito 5.11.0 gap loi module/mock khi mock interface trong module Java.
- JaCoCo 0.8.12 gap loi:
  - `Unsupported class file major version 69`
- Major version 69 la class file cua Java 25.

Ket luan: neu chuan hoa len JDK 25 thi phai nang dong bo Mockito, JaCoCo, Surefire va JavaFX.

### 1.4. Loi `module-info.java` lien quan `java.sql` trong IntelliJ

Anh chup man hinh cho thay IntelliJ bao:

- `JDK "ms-21" is missing`
- `SDK is not specified or corrupted for 1 module`

Do `.idea/misc.xml` van tro toi SDK local ten `ms-21`, IntelliJ khong resolve duoc JDK/module chuan. Vi vay `requires java.sql;` bi do theo day chuyen.

Ket luan: `requires java.sql;` khong sai. Loi trong anh la loi cau hinh SDK cua IntelliJ, khong phai loi code Java.

### 1.5. Kha nang loi runtime voi MySQL JDBC module

Project dung MySQL JDBC driver, nhung `module-info.java` ban dau chi co:

```java
requires java.sql;
```

`java.sql` chi la API JDBC. MySQL connector jar `mysql-connector-j-8.0.33.jar` la automatic module ten:

```text
mysql.connector.j
```

Neu chay app theo module path, nen khai bao ro module MySQL driver de runtime resolve on dinh.
